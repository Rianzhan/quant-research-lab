# 多资产 ETF 机器学习研究实验室

这是项目的脱敏工程展示版，用于审阅研究设计、实现和测试。公开仓库保留已验收源码、关键配置和合成测试；不包含行情、封存留出集、预测、训练好的模型、私人实验结果或旧 Git 历史。

核心问题是：历史日线信息能否提供稳定的未来五交易日样本外预测证据，以及这种证据能否在真实记账与摩擦假设下转化为历史经济价值。

值得查看的能力证据包括：

- 按资产与权益事件片段计算特征，未来数据扰动不能改变过去特征。
- 使用真实 `label_end_date` 清除跨训练/测试边界的重叠标签。
- 单资产与汇总模型共用 17 列特征、日期和样本规则。
- t 日收盘决策、下一会话执行，不能用未来开盘价反算订单。
- 分红应收与现金分离、折算不凭空制造盈亏、每日账本对账。
- 固定策略和评价协议，保留弱结果与失败的研究结论。

开发期结论是 **Level 1：局部或弱历史经济信号，稳定性不足**。不能把它改写为“模型会赚钱”。最终窗口曾发生目标相关的外部信息意外暴露，因此永久不再称为完全未见留出集；事件和统计身份见 [研究诚信说明](research-integrity.md)。

本项目使用 AI 辅助开发；研究问题、阶段范围、协议冻结与关键判断由人类主导并验收。它展示可迁移的研究工程方法，不冒称自然科学发现或未经辅助的个人独立编程成果。

安装与运行见 [英文首页](../README.md)。测试和 demo 均使用合成输入，不下载或打开真实行情。金融研究中仍应检查：前视偏差、幸存者偏差和交易成本。
